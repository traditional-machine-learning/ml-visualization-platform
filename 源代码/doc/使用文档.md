# 机器学习算法仿真实验和学习平台使用文档

#### 注意：本项目可以使用docker，前后端或者云端三种方式打开

## 1. 项目简介

本项目是一个面向传统机器学习算法学习与实验的 Web 平台，采用 **Spring Boot 后端 + Angular 前端 + MySQL 数据库** 的前后端分离架构。

系统支持算法与数据集选择、参数配置、训练控制、过程可视化、评估指标展示、模型解释、实验案例引导、模型对比、特征工程模拟以及 AI 助手等功能。用户可以通过网页完成一次完整的机器学习实验流程，并观察训练过程中模型状态和指标变化。

项目 GitHub 地址：

```text
https://github.com/3r41fy/web_group_pj/tree/master
```

## 2.使用方式——docker

从 GitHub 获取代码后，推荐优先使用 Docker 运行。该方式会同时启动 MySQL、Spring Boot 后端和 Angular 前端，不需要分别配置前后端环境。

### 2.1 环境要求

请确认已安装并启动：

- Docker Desktop
- Docker Compose

### 2.2 获取代码

```powershell
git clone https://github.com/3r41fy/web_group_pj.git
cd web_group_pj
git checkout master
```

### 2.3 启动项目

在项目根目录执行：

```powershell
docker compose up --build
```

如果希望后台运行，可以使用：

```powershell
docker compose up -d --build
```

启动成功后访问：

```text
http://localhost/
```

说明：

- Docker 会启动 `ml-platform-mysql`、`ml-platform-backend`、`ml-platform-frontend` 三个容器。
- 前端容器通过 Nginx 对外提供页面服务。
- 前端请求 `/api` 时，会由 Nginx 转发到后端容器。
- Docker 模式下不需要单独运行 `npm start` 或 `mvn spring-boot:run`。

### 2.4 Docker 常见问题

如果提示 Docker Engine 连接失败，例如出现 `dockerDesktopLinuxEngine` 相关报错，说明 Docker Desktop 没有启动或 Docker Engine 尚未就绪。请先打开 Docker Desktop，等待其显示正在运行后再执行命令。

如果提示 `3306` 端口被占用，说明本机已有 MySQL 正在占用该端口。可以选择以下方式之一：

- 停止本机 MySQL 服务后重新执行 `docker compose up --build`。
- 或改用本文第 3 节的本地前后端分开运行方式。

如果需要重新初始化 Docker 数据库，可以执行：

```powershell
docker compose down -v
docker compose up --build
```

查看容器日志：

```powershell
docker compose logs backend
docker compose logs frontend
docker compose logs mysql
```

## 3. 本地开发方式：前后端分别启动

如果不使用 Docker，也可以手动启动 MySQL、后端和前端。该方式更适合开发调试。

### 3.1 环境要求

| 工具 | 建议版本 | 用途 |
|---|---:|---|
| JDK | 17+ | 运行 Spring Boot 后端 |
| Maven | 3.8+ | 构建和启动后端 |
| Node.js | 18+ | 运行 Angular 前端 |
| npm | 随 Node.js 安装 | 安装前端依赖 |
| MySQL | 8.0+ | 保存算法、数据集和实验基础数据 |

### 3.2 数据库准备

登录 MySQL：

```powershell
mysql -u root -p
```

创建数据库：

```sql
CREATE DATABASE IF NOT EXISTS ml_platform
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;
EXIT;
```

如需手动导入初始化脚本，可执行：

```powershell
mysql -u root -p ml_platform < backend\src\main\resources\schema.sql
```

### 3.3 后端配置

根据本机 MySQL 用户名和密码修改：

```text
backend/src/main/resources/application.yml
```

示例：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/ml_platform?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useUnicode=true&characterEncoding=UTF-8
    username: root
    password: your_password
```

如果需要使用 AI 助手，请在同一配置文件中补充大模型 API key。若不使用 AI 助手，可以保持为空或使用默认配置。

### 3.4 启动后端

在项目根目录或后端目录执行：

```powershell
cd backend
mvn spring-boot:run
```

后端默认地址：

```text
http://localhost:8080
```

### 3.5 启动前端

打开另一个终端窗口：

```powershell
cd frontend
npm install
npm start
```

前端默认地址：

```text
http://localhost:4200
```

实验页面地址：

```text
http://localhost:4200/experiment
```

说明：本地开发模式下，前端通过 `proxy.conf.json` 将 `/api` 请求转发到 `http://localhost:8080`，因此需要先保证后端服务已经启动。

## 4. 云服务器部署说明

项目支持云服务器部署，部署方式与 Docker 运行方式一致：在服务器上安装 Docker 和 Docker Compose 后，在项目根目录执行：

```bash
docker compose up -d --build
```

然后开放服务器对应访问端口，即可通过服务器公网地址访问前端页面。

本项目已进行云服务器部署，云端访问地址为：

```text
http://43.143.104.103/
```

若评测时云端服务暂时无法访问，可使用本文第 2 节 Docker 方式或第 3 节本地开发方式运行项目。

## 5. 基本使用流程

### 5.1 进入实验页面

Docker 运行方式：

```text
http://localhost/
```

本地前后端分开运行方式：

```text
http://localhost:4200/experiment
```

页面主要分为：

- 左侧：算法选择、数据集选择、模型对比、特征工程等模块。
- 中间：可视化画布和评估指标面板。
- 右侧：参数配置、训练控制、训练日志、模型解释。
- 下方：实验案例库和学习引导。

### 5.2 选择算法和数据集

用户可以在页面左侧选择算法和数据集。

支持的算法包括：

- 线性回归
- 逻辑回归
- 决策树
- K-means
- SVM
- 随机森林
- PCA 等扩展算法

支持的数据集包括：

- Iris 鸢尾花数据集
- Boston Housing 房价数据集
- 合成分类数据集
- 小型 CSV 数据上传

### 5.3 配置参数

在右侧参数面板中可以调整算法参数，例如：

- 学习率
- 迭代次数
- K-means 聚类数 K
- 决策树最大深度
- SVM 核函数、C、gamma 等

### 5.4 控制训练过程

训练控制区提供：

- 开始训练
- 暂停
- 继续
- 单步执行
- 重置

连续训练时，系统会逐步更新训练状态；单步执行时，每次只推进一步，便于观察训练过程。

### 5.5 查看过程可视化

可视化画布会根据算法类型展示不同内容：

| 任务类型 | 可视化内容 |
|---|---|
| 分类 | 数据散点图、决策边界 |
| 回归 | 数据散点图、回归线 |
| 聚类 | 数据散点图、聚类中心 |
| 降维 | PCA 二维投影结果 |

### 5.6 查看评估指标

评估指标面板会根据任务类型展示不同指标。

分类任务：

- Accuracy
- Precision
- Recall
- F1

回归任务：

- R²
- MAE
- MSE
- Loss Drop

聚类任务：

- Silhouette
- Inertia
- Cluster Count
- Stability

同时，面板会使用 ECharts 展示训练曲线，例如 Loss 下降和 Score 上升。

### 5.7 查看模型解释

模型解释区域会根据算法类型展示不同解释方式：

- 决策树：展示树结构和节点分裂条件。
- 线性模型：展示特征权重条形图。
- K-means：展示聚类中心状态摘要。
- SVM：展示支持向量和分类边界摘要。

### 5.8 使用实验案例库

实验案例库提供预设实验，用户点击案例后系统会自动加载推荐算法、数据集和参数。

案例示例：

- 用 K-means 对 Iris 数据进行聚类。
- 用决策树对 Iris 数据进行分类。
- 用逻辑回归观察特征权重。
- 用线性回归观察误差曲线。
- 用 SVM 观察分类边界。

案例库会根据当前训练状态展示引导阶段，帮助用户完成实验。

## 6. 学习引导系统使用说明

学习引导系统主要用于帮助用户理解机器学习实验过程，而不是只查看最终结果。它包括：

1. **模型解释可视化**
   - 决策树显示树结构。
   - 线性模型显示特征权重。
   - 聚类和 SVM 显示摘要解释。

2. **评估指标面板**
   - 根据任务类型展示不同指标。
   - 使用图表展示训练过程变化。

3. **实验案例库**
   - 提供预设案例。
   - 自动填充算法、数据集和参数。
   - 根据训练状态显示引导步骤。

4. **训练日志**
   - 展示训练开始、单步更新、收敛提示和训练完成等信息。
   - 将训练过程转化为文字叙事。

## 7. 常见问题

### 7.1 Docker 无法连接 Docker Engine

如果出现 `dockerDesktopLinuxEngine` 相关报错，请先启动 Docker Desktop，并等待 Docker Engine 完全启动。

### 7.2 Docker 启动时 3306 端口被占用

说明本机 MySQL 正在使用 3306 端口。可以关闭本机 MySQL，或改用本地开发方式运行项目。

### 7.3 后端启动时报数据库密码错误

请检查：

```text
backend/src/main/resources/application.yml
```

确认用户名和密码与本机 MySQL 一致。

### 7.4 前端请求 `/api` 返回 HTML

如果控制台出现 `Unexpected token '<'`，通常说明前端请求拿到的是 `index.html`，不是后端 JSON。

请确认：

- 本地开发方式下，使用 `npm start` 启动前端。
- 后端 `http://localhost:8080` 已经启动。
- Docker 方式下，访问 `http://localhost/`，不要访问 `http://localhost:4200`。

### 7.5 页面出现空数据

可能原因：

- 后端未启动。
- 数据库未初始化。
- 算法或数据集接口请求失败。
- Docker 数据卷中保留了旧数据或错误初始化状态。

可以尝试：

```powershell
docker compose down -v
docker compose up --build
```

或检查后端日志和数据库配置。

# 部署说明文档

## 1. 本地开发环境部署

### 1.1 环境要求
- JDK 17+
- Node.js 18+
- MySQL 8.0+
- Maven 3.8+

### 1.2 后端配置

1. 安装JDK 17和Maven

2. 配置MySQL数据库：
```bash
# 创建数据库
mysql -u root -p
CREATE DATABASE ml_platform;

# 执行初始化脚本
mysql -u root -p ml_platform < backend/src/main/resources/schema.sql
```

3. 修改数据库配置：
编辑 `backend/src/main/resources/application.yml`：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/ml_platform
    username: root
    password: your_password
```

4. 启动后端：
```bash
cd backend
mvn spring-boot:run
```

后端启动在 `http://localhost:8080`

### 1.3 前端配置

1. 安装Node.js依赖：
```bash
cd frontend
npm install
```

2. 启动前端开发服务器：
```bash
ng serve
```

前端启动在 `http://localhost:4200`

## 2. Docker部署

### 2.1 生产环境
- Docker 20+
- docker-compose 2.0+

### 2.2 构建并启动所有服务

```bash
# 在项目根目录执行
docker-compose up -d --build
```

这将启动：
- MySQL数据库 (端口3306)
- 后端服务 (端口8080)
- 前端服务 (端口8066)

### 2.3 故障排查

若Docker容器启动失败：

查看日志：`docker-compose logs backend/frontend/mysql`

### 2.4 单独构建镜像

**构建后端镜像：**
```bash
docker build -f Dockerfile.backend -t ml-platform-backend:latest ./backend
```

**构建前端镜像：**
```bash
docker build -f Dockerfile.frontend -t ml-platform-frontend:latest ./frontend
```

## 3. 云服务器部署

### 3.1 准备云服务器

推荐配置：
- CPU: 2核+
- 内存: 4GB+
- 存储: 40GB+
- 操作系统: Ubuntu 20.04 / CentOS 7+

### 3.2 安装Docker

**Ubuntu:**
```bash
sudo apt update
sudo apt install docker.io docker-compose
sudo systemctl start docker
sudo systemctl enable docker
```

**CentOS:**
```bash
sudo yum install docker docker-compose
sudo systemctl start docker
sudo systemctl enable docker
```

### 3.3 部署应用

1. 上传项目文件到服务器
```bash
scp -r web_group_pj user@server:/home/user/
```

2. 在服务器上执行
```bash
cd /home/user/web_group_pj
docker-compose up -d --build
```

3. 配置防火墙开放端口
```bash
# Ubuntu
sudo ufw allow 80
sudo ufw allow 8080

# CentOS
sudo firewall-cmd --add-port=80/tcp --permanent
sudo firewall-cmd --reload
```

## 4. 数据库维护

### 4.1 数据备份
```bash
docker exec ml-platform-mysql mysqldump -u root -p ml_platform > backup.sql
```

### 4.2 数据恢复
```bash
docker exec -i ml-platform-mysql mysql -u root -p ml_platform < backup.sql
```

### 2.2 Service层详细说明

#### 2.2.1 TrainingSimulationService.java

**路径**: `backend/src/main/java/com/mlplatform/service/TrainingSimulationService.java`

**核心类，实现所有算法的训练仿真逻辑**

**主要方法**：

| 方法签名 | 功能描述 |
|---------|---------|
| `trainLinearRegression(Long sessionId, DatasetDTO dataset, int iterations)` | 线性回归训练（梯度下降） |
| `trainLogisticRegression(Long sessionId, DatasetDTO dataset, int iterations)` | 逻辑回归训练（梯度下降+Sigmoid） |
| `trainKMeans(Long sessionId, DatasetDTO dataset, int k, int iterations)` | K-Means聚类训练（EM迭代） |
| `trainDecisionTree(Long sessionId, DatasetDTO dataset, int maxDepth)` | 决策树训练（贪心分裂） |
| `trainSvm(Long sessionId, DatasetDTO dataset, String kernel, double C)` | SVM训练（支持多种核函数） |
| `computePca(Long sessionId, DatasetDTO dataset, int nComponents)` | PCA降维计算 |
| `startRandomForest(Long sessionId, DatasetDTO dataset, int nTrees, int maxDepth)` | 随机森林训练 |
| `performStep(Long sessionId)` | 执行单步训练推进 |

**算法实现细节**：

**1. 线性回归**

```java
// 核心实现逻辑
// 1. 初始化权重 weights = [0, 0], bias = 0
// 2. 梯度下降迭代：
//    prediction = X * weights + bias
//    loss = MSE(prediction, y)
//    grad_w = -2/n * X.T * (y - prediction)
//    grad_b = -2/n * sum(y - prediction)
//    weights -= learningRate * grad_w
//    bias -= learningRate * grad_b
// 3. 可视化数据：回归线方程 y = w*x + b
```

**2. 逻辑回归**

```java
// 核心实现逻辑
// 1. 初始化权重和偏置
// 2. 梯度下降迭代：
//    sigmoid = 1 / (1 + exp(-z))
//    loss = -sum(y*log(p) + (1-y)*log(1-p))  // 交叉熵
//    计算梯度并更新
// 3. 可视化数据：决策边界 weights*x + bias = 0
```

**3. K-Means聚类**

```java
// 核心实现逻辑
// 1. 初始化聚类中心（随机选择K个点）
// 2. EM迭代：
//    E步：每个点分配到最近的聚类中心
//    M步：更新聚类中心为新分配点的均值
// 3. 可视化数据：聚类中心坐标、点分配结果
// 4. 评估：轮廓系数、惯性
```

**4. 决策树**

```java
// 核心实现逻辑
// 1. 从根节点开始
// 2. 对每个特征寻找最佳分裂阈值（最大化信息增益/Gini减少）
// 3. 分裂节点，递归处理子节点
// 4. 终止条件：深度限制、纯度达标
// 5. 可视化数据：分裂特征、阈值、树结构
```

**5. SVM**

```java
// 支持三种核函数：
// - Linear: decision_boundary = w*x + b
// - RBF: 使用高斯核映射
// - Polynomial: 使用多项式核
// 简化实现：迭代优化决策边界
```

**6. PCA**

```java
// 核心实现逻辑：
// 1. 数据标准化（均值归零）
// 2. 计算协方差矩阵
// 3. 特征值分解
// 4. 选择top-N主成分
// 5. 数据投影到主成分空间
// 6. 可视化：降维后投影点
```

**7. 随机森林**

```java
// 核心实现逻辑：
// 1. Bootstrap采样（有放回抽样）
// 2. 训练nTrees棵决策树
// 3. 每棵树随机选择部分特征
// 4. 集成投票预测
// 5. 可视化：特征重要性排序
```

```typescript
// 连续训练逻辑
runContinuousTraining() {
    const interval = setInterval(() => {
        if (this.trainingState.status === 'paused' || 
            this.trainingState.status === 'completed') {
            clearInterval(interval);
            return;
        }
        this.onTrainStep();
    }, 850);  // 850ms间隔
}

// 单步训练调用
async onTrainStep() {
    const response = await this.apiService.trainStep(
        this.selectedAlgorithm!.id,
        this.sessionId!,
        this.selectedDataset!.id,
        this.parameterValues
    );
    this.updateTrainingState(response.data);
    this.updateVisualization(response.data.modelData);
}
```

#### 3.1.2 VisualizationCanvasComponent

**路径**: `frontend/src/app/components/visualization-canvas/visualization-canvas.component.ts`

**ECharts可视化渲染组件**

**输入属性**：
- `@Input() dataPoints`: 数据点数组
- `@Input() modelData`: 模型可视化数据
- `@Input() algorithmType`: 算法类型（classification/regression/clustering）

**核心渲染逻辑**：

```typescript
renderChart() {
    // 1. 处理PCA数据（优先检测）
    if (modelData?.pcaTransformed) {
        this.renderPcaProjection(modelData.pcaTransformed);
        return;
    }

    // 2. 按标签分组数据点
    const grouped = this.groupPointsByLabel(this.dataPoints);

    // 3. 构建ECharts series
    const series = [];
    for (const [label, points] of Object.entries(grouped)) {
        series.push({
            type: 'scatter',
            name: label,
            data: points.map(p => [p.x, p.y]),
            symbolSize: 10,
            itemStyle: { color: this.getColorForLabel(label) }
        });
    }

    // 4. 添加叠加层（决策边界/回归线/聚类中心）
    const overlaySeries = this.getOverlaySeries(modelData);
    series.push(...overlaySeries);

    // 5. 设置ECharts配置
    this.chart.setOption({
        xAxis: { type: 'value' },
        yAxis: { type: 'value' },
        series: series,
        legend: { show: true },
        animation: true
    });
}
```

## 7. 进阶功能实现原理

### 7.1 PCA降维算法实现

**实现原理**：

PCA（主成分分析）是一种线性降维技术，通过提取数据的主要变化方向来降低维度。

**核心步骤**：
1. **数据标准化**：将数据均值归零
2. **协方差矩阵计算**：`Cov(X) = (X-mean)^T * (X-mean) / n`
3. **特征值分解**：计算协方差矩阵的特征值和特征向量
4. **主成分选择**：选择top-N个最大特征值对应的特征向量
5. **数据投影**：将原始数据投影到主成分空间

**关键代码逻辑**：

```java
// TrainingSimulationService.computePca()
public ModelData computePca(DatasetDTO dataset, int nComponents) {
    // 1. 提取数据矩阵
    double[][] data = extractDataMatrix(dataset);

    // 2. 标准化
    double[] mean = computeMean(data);
    double[][] centered = subtractMean(data, mean);

    // 3. 协方差矩阵
    double[][] cov = computeCovariance(centered);

    // 4. 特征值分解（简化实现）
    EigenDecomposition eig = new EigenDecomposition(cov);

    // 5. 选择主成分
    double[][] components = selectTopComponents(eig, nComponents);

    // 6. 投影
    double[][] projected = multiply(centered, transpose(components));

    // 返回可视化数据
    ModelData modelData = new ModelData();
    modelData.setPcaComponents(components);
    modelData.setPcaTransformed(projected);
    return modelData;
}
```

### 7.2 随机森林算法实现

**实现原理**：

随机森林是一种集成学习方法，通过组合多棵决策树来提高预测准确性和稳定性。

**核心思想**：
- **Bootstrap采样**：每棵树使用不同的随机采样数据
- **特征随机**：每次分裂只考虑部分特征
- **投票集成**：多棵树的预测结果投票决定最终分类

**关键代码逻辑**：

```java
// TrainingSimulationService.startRandomForest()
public ModelData startRandomForest(DatasetDTO dataset, int nTrees, int maxDepth) {
    List<TreeResult> trees = new ArrayList<>();

    for (int i = 0; i < nTrees; i++) {
        // 1. Bootstrap采样
        List<DataPoint> bootstrapSample = bootstrapSample(dataset.getDataPoints());

        // 2. 训练单棵树（带特征随机）
        TreeResult tree = trainTreeWithFeatureRandom(bootstrapSample, maxDepth);

        trees.add(tree);
    }

    // 3. 计算特征重要性
    List<FeatureImportance> importances = computeFeatureImportances(trees);

    // 返回可视化数据
    ModelData modelData = new ModelData();
    modelData.setFeatureImportances(importances);
    return modelData;
}
```

### 7.3 模型对比功能实现

**实现原理**：

允许用户在同一个数据集上运行多个算法或参数配置，对比性能指标。

**关键代码逻辑**：

```java
// ComparisonController.compareModels()
public ComparisonResult compareModels(ComparisonRequest request) {
    List<ModelPerformance> performances = new ArrayList<>();

    for (Config config : request.getConfigurations()) {
        // 1. 训练模型
        TrainingSimulationResponse response = trainingService.train(
            config.getAlgorithmId(),
            request.getDatasetId(),
            config.getParams()
        );

        // 2. 记录性能指标
        ModelPerformance perf = new ModelPerformance();
        perf.setAlgorithmName(response.getAlgorithmName());
        perf.setAccuracy(response.getAccuracy());
        perf.setLoss(response.getLoss());
        perf.setTrainingTime(response.getTotalSteps());

        performances.add(perf);
    }

    // 3. 排序并返回
    return new ComparisonResult(performances);
}
```

# 传统机器学习算法仿真实验平台 - 设计文档

## 1. 系统概述

### 1.1 系统目标

本系统是一个面向机器学习初学者的可视化学习平台，旨在通过交互式、可视化的方式，帮助用户直观理解传统机器学习算法的工作原理。系统支持监督学习、无监督学习两大类经典算法，提供完整的训练控制、过程可视化和学习引导功能。

### 1.2 技术架构

本系统采用前后端分离的B/S架构：

| 层级 | 技术选型 | 说明 |
|-----|---------|------|
| **前端** | Angular 17+ | 现代化前端框架，组件化开发 |
| **UI框架** | Angular Material | Material Design风格UI组件库 |
| **可视化** | ECharts | 专业数据可视化库 |
| **后端** | Spring Boot 3.x | Java企业级应用框架 |
| **持久层** | MyBatis | 轻量级ORM框架，注解方式 |
| **数据库** | MySQL 8.0 | 关系型数据库 |
| **部署** | Docker + docker-compose | 容器化部署 |

## 6. 核心算法设计

### 6.1 算法仿真策略

本系统采用**简化教学版本**实现算法，核心设计原则：

1. **步骤可拆解**：训练过程可分解为多个步骤
2. **状态可保存**：每步训练结果可持久化
3. **过程可可视化**：关键数据可映射为可视化元素

### 6.2 各算法设计要点

#### 6.2.1 线性回归

**算法原理**：梯度下降优化MSE损失

**训练步骤**：
1. 初始化权重和偏置
2. 计算预测值和损失
3. 计算梯度
4. 更新权重（learning_rate * gradient）
5. 重复迭代

**可视化**：
- 回归线：y = w*x + b
- 损失曲线：MSE随迭代下降

#### 6.2.2 逻辑回归

**算法原理**：梯度下降优化交叉熵损失

**训练步骤**：
1. 初始化权重和偏置
2. 计算sigmoid概率
3. 计算交叉熵损失
4. 计算梯度
5. 更新权重
6. 重复迭代

**可视化**：
- 决策边界：w*x + b = 0
- 损失曲线：交叉熵随迭代下降
- 准确率曲线：分类准确率变化

#### 6.2.3 决策树

**算法原理**：贪心分裂，最大化信息增益/Gini减少

**训练步骤**：
1. 选择最佳分裂特征和阈值
2. 分割数据集
3. 对子节点递归分裂
4. 达到深度限制或纯度阈值停止

**可视化**：
- 树结构：节点、分裂条件、叶节点
- 决策边界：矩形区域划分

#### 6.2.4 K-Means聚类

**算法原理**：EM迭代，最小化惯性

**训练步骤**：
1. 初始化聚类中心（随机选择）
2. E步：分配点到最近中心
3. M步：更新中心位置
4. 重复迭代直到收敛

**可视化**：
- 聚类中心：大号标记点
- 数据点按聚类着色
- 轮廓系数曲线

#### 6.2.5 SVM

**算法原理**：最大间隔分类（简化版）

**支持核函数**：
- Linear：线性决策边界
- RBF：非线性边界（高斯核）
- Polynomial：多项式边界

**可视化**：
- 决策边界
- 支持向量（可选）

#### 6.2.6 PCA

**算法原理**：协方差矩阵特征分解

**计算步骤**：
1. 数据标准化
2. 计算协方差矩阵
3. 特征值分解
4. 选择主成分
5. 数据投影

**可视化**：
- 降维后投影点散点图
- 特征重要性（贡献率）

#### 6.2.7 随机森林

**算法原理**：Bootstrap + 多棵决策树投票

**训练步骤**：
1. Bootstrap采样
2. 训练多棵决策树
3. 特征随机选择
4. 集成投票预测

**可视化**：
- 特征重要性排序
- 预测结果

## 8. 扩展性设计

### 8.1 算法扩展

新增算法需：
1. 在数据库algorithm表添加记录
2. 在TrainingSimulationService添加训练方法
3. 在前端添加参数面板配置（可选）

### 8.2 数据集扩展

新增数据集需：
1. 在数据库dataset表添加记录
2. 格式符合features/data_content JSON结构

### 8.3 可视化扩展

新增可视化类型需：
1. 在VisualizationCanvasComponent添加渲染逻辑
2. 在modelData中添加对应数据结构
